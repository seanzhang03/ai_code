## 一、基础语法

> 来源：1.print、2.数据类型、3.if、4.input、5.for、6.各位拆分、7.break,continue,pass

### 1.1 输出与格式化（1.print）

Python 有 **三种格式化输出方式**：

| 方式 | 语法 | 特点 |
|---|---|---|
| `format()` | `"{}".format(var)` | 可加精度 `{:.2f}`（保留 2 位小数） |
| `%` 占位 | `"%s %d" % (name, age)` | `%s` 字符串、`%d` 整数、`%f` 浮点 |
| f-string | `f"{name} is {age}"` | 最直观，`{}` 内可直接写表达式 |

- `m.n` 规则：`m` 指定总位数，`n` 指定小数精度。

### 1.2 数据类型与 type()（2.数据类型）

- 基本类型：`int`、`float`、`bool`、`str`
- 容器类型：`list`、`tuple`（元组）、`set`（集合）、`dict`（字典）
- 用 `type(obj)` 查看对象的数据类型。

### 1.3 input() 函数（4.input）

- `input("提示词")` 获取用户输入，**返回值永远是字符串**。
- 做数值运算前必须类型转换：`int(input(...))`、`float(input(...))`。

### 1.4 if 分支（3.if）

```python
if 条件:
    ...
elif 条件:      # 可以有多个 elif
    ...
else:
    ...
```

### 1.5 for 循环与 range（5.for）

- `range(start, stop, step)`：**含 start，不含 stop**；start 默认为 0，step 默认为 1；step 可为负数，不能为 0。
- `len(obj)`：返回对象长度，适用于字符串、列表、元组、字典等。
- `for i in 可迭代对象:` 直接遍历元素。

### 1.6 数值拆分技巧（6.各位拆分）

- `num % 10` 取个位（取余）
- `num // 10 % 10` 取十位——注意 Python 必须用 **`//` 整除**（`/` 是浮点除法）。

### 1.7 break / continue / pass（7）

- `break`：跳出当前**整个循环**。
- `continue`：跳过本次循环剩余代码，进入下一次循环。
- `pass`：**占位符**，用于尚未实现功能的代码块（函数、类、分支），防止语法报错。

### 1.8 特殊值（7）

- `id(obj)`：查看对象在内存中的地址。
- `float('inf')` / `float('-inf')`：正负无穷大；`NaN` 表示"不是数字"。

## 二、字符串与下标切片

> 来源：8.字符串的函数、9.下标访问和切片访问

### 2.1 下标与切片（9）

```python
str[起始:终止:步长]   # 含起始，不含终止；步长默认为 1
str[0:4:2]   # 取下标 0、2
str[::-1]    # 步长为负 → 倒序输出整个字符串
```

- 步长为负数时，终止位置必须在起始位置的**左侧**（如 `str[8:-1:-1]` 不合法）。

### 2.2 字符串查询函数（8）

| 函数 | 说明 |
|---|---|
| `find(sub)` | 返回第一个匹配的**索引**，找不到返回 **-1** |
| `index(sub)` | 同 find，但找不到**直接报错** |
| `rfind` / `rindex` | 从右往左查找 |

### 2.3 字符串转换 / 判断 / 分割 / 其他（8）

- **转换**：`upper()` 全大写、`lower()` 全小写、`title()` 每个单词首字母大写、`capitalize()` 仅第一个字符大写。
- **判断**：`startswith()`、`endswith()`、`isspace()`（纯空格）、`isalnum()`（纯字母数字）、`isdigit()`（纯数字）、`isalpha()`（纯字母）。
- **分割**：
  - `partition(sep)` → 返回 **3 元素元组**（分隔符前、分隔符、分隔符后）；找不到则返回 (原串, '', '')。`rpartition` 从右分割。
  - `split(sep, 次数)` → 返回 **列表**，分隔符不保留；不传参数按空白分割。
  - `splitlines()` 按行分割。
- **其他**：`count()` 统计出现次数；`join(序列)` 用分隔符连接序列（元素必须都是字符串）；`replace(old, new, 次数)` 替换并返回新字符串。

## 三、容器数据类型

> 来源：10.列表、11.元组、12.集合、13.字典

### 3.1 列表 list（10）

- **有序、可修改**，元素可以是任意类型；支持下标/切片访问；`+` 拼接、`*` 重复。

**增删改查**：

| 操作 | 方法 | 说明 |
|---|---|---|
| 增 | `append(x)` | 末尾追加一个元素 |
| 增 | `insert(i, x)` | 在位置 i 插入 |
| 增 | `extend(可迭代)` | 批量追加到末尾 |
| 删 | `remove(x)` | 删除指定元素（返回 None） |
| 删 | `pop(i)` | 删除并**返回**指定位置元素，默认删最后一个 |
| 删 | `clear()` | 清空 |
| 删 | `del list[i]` | 删除下标元素；不加下标删除整个对象 |
| 改 | 下标 / 切片赋值 | 切片赋值时数量要一致 |
| 查 | `index(x)` | 列表**没有** find 方法 |

**排序与反转**：`reverse()` 原地反转（返回 None）；`sort(reverse=, key=)` 原地排序，如 `sort(key=len)` 按长度排。

### 3.2 浅拷贝与深拷贝（10，高频考点）

- **浅拷贝** `copy()`：新对象与原对象内容一致，但**内部可变元素仍是原引用**（不可变元素如数字、字符串互不影响）。
- **深拷贝** `copy.deepcopy()`：新对象及其内部所有元素**完全独立**。
- 判断：`id(a) == id(b)` 说明是同一个对象。

### 3.3 列表推导式（10，高频考点）

```python
[x ** 2 for x in list8]                    # 无筛选
[x ** 2 for x in list8 if x <= 4]          # 带条件
[y for x in list11 for y in x]             # 两层嵌套（外层循环在前）
```

### 3.4 元组 tuple（11）

- 与列表相似但**元素不可修改**（不可变），用 `()` 定义。
- 支持 `len/max/min/in/not in`，可用 `del` 删除整个元组。
- **序列通用函数**：
  - `sorted(seq, reverse=)` 返回排序后的**新列表**，原序列不变（区别于 list 的原地 `sort`）。
  - `reversed(seq)` 返回反转的迭代器。
  - `all(seq)`：全部为 True 才 True；`any(seq)`：至少一个 True 即 True。
  - `sum(seq)` 求和；`min/max` 可用 `default=` 指定空序列提示。
  - `enumerate(seq, start=)`：返回 (下标, 元素) 枚举对象。
  - `zip(a, b)`：把多个可迭代对象对应位置打包成元组，以**最短的为准**。 
  - `map(func, seq)`：把 func 作用于每个元素（函数名**不加括号**）。
  - `filter(func, seq)`：保留 func 返回 True 的元素，如 `filter(str.isdigit, tuple5)`。

### 3.5 集合 set（12）

- **无序、元素不重复**；元素必须是**不可变类型**（数字、字符串、元组），常用来**去重**。
- 增删：`add()` 加一个；`update()` 加多个（参数需是可迭代对象）；`remove()` 不存在报错；`discard()` 不存在不报错；`pop()` **随机**删除一个并返回（与列表不同）。
- 运算：`intersection()` 交集、`union()` 并集、`issubset()` 判断子集、`issuperset()` 判断父集。
- `set()` 创建可变集合（参数必须可迭代，`set()` 创建空集合）；`frozenset()` 创建**不可变集合**（元素个数也不可变）。

### 3.6 字典 dict（13）

- **无序**的键值对集合（键值对可修改）；**键唯一**（重复定义则覆盖）且**键必须不可变**（不能是列表）；值可为任意类型。
- **修改**：`d[key] = value`；`update({...})` 批量修改/新增。
- **查找**：
  - `d[key]`：键不存在**报错**。
  - `get(key, 默认值)`：不存在返回默认值（默认 None）。
  - `setdefault(key, 默认值)`：存在返回原值；不存在则**新增**该键值对并返回默认值。
- **删除**：`pop(key)` 删除并返回 value；`del d[key]`。
- **其他**：`keys()` / `values()` / `items()` 分别返回键、值、键值对视图；`copy()` 浅拷贝。
- **字典推导式**：`{y: y**2 for y in range(1, 6)}`。

## 四、函数

> 来源：14.函数

### 4.1 定义与调用

- `def 函数名(参数):` 定义；**定义时只检查语法不执行**，调用时才执行。
- `return` 返回结果，无 return 默认返回 `None`；**返回多个值自动打包成元组**。

### 4.2 参数类型（高频考点）

| 类型 | 说明 |
|---|---|
| 位置参数 | 实参顺序、个数与形参一致 |
| 关键字参数 | `func(y=2, x=1)`，一旦用关键字传参，后面的实参**都不能再用位置传参** |
| 默认参数 | `def f(x, y, z=1)`，默认参数**必须放在最右边**；不传用默认值，传了则覆盖 |
| 不定长位置参数 `*args` | 多余位置实参打包成**元组**；若其右边还有形参，必须用关键字传参 |
| 不定长关键字参数 `**kwargs` | 多余关键字实参打包成**字典** |

- 混合顺序：`def mix(x, *args, **kwargs)`。
- **解包**：`func(*元组)` 把元组元素逐个传给形参；`func(**字典)` 要求字典的 key 与形参名**一一对应**（顺序可不同）。

### 4.3 作用域（高频考点）

- 局部变量（函数内）与全局变量（函数外）；函数内可**读**全局变量，函数外**不能访问**局部变量。
- 局部与全局同名时，函数内局部优先。
- `global 变量`：在函数内将变量声明为全局变量（函数内外同步修改）。
- `nonlocal 变量`：在内层函数中修改**上一层嵌套函数**的变量；global 与 nonlocal 不能对同一变量生效。
- 注意：自定义函数名**不要与内置函数同名**，否则会覆盖内置函数。

### 4.4 嵌套函数与闭包（高频考点）

- 内部函数只能在外部函数中调用，或作为返回值返回后调用。
- **闭包**：内函数访问外函数的变量，该变量**不会随外函数调用结束而销毁**，而是被内函数保留：

```python
def nth_power(exponent):        # 外函数
    def exponent_of(base):      # 内函数
        return base ** exponent
    return exponent_of          # 返回内函数（不带括号）
square = nth_power(2); square(3)  # 9
```

### 4.5 lambda 匿名函数

- 语法：`lambda 参数列表: 表达式`；**只能有一个表达式，自带 return**；生命周期短，调用后立即回收。
- 例：`res = lambda x, y: x + y`。

### 4.6 内置函数

- `abs()` 绝对值；`round(x, n)` 四舍五入保留 n 位小数；`help(函数名)` 查看说明文档（函数名**不带括号**）。

## 五、面向对象

> 来源：15.类、16.封装、17.继承、18.多态

### 5.1 类与对象基础（15，高频考点）

- Python 中**一切皆对象**；对象必须依托类的实例化创建，一个类可实例化无数对象；**对象之间的属性和行为不共享**。
- **self**：表示对象自身，存放对象自身地址；想让方法被对象调用，**第一个参数必须是 self**（把对象与类方法绑定）。
- `__init__(self, ...)` **构造函数**：创建对象时自动调用，用于初始化属性。
- `__del__(self)` **析构函数**：对象引用清零（销毁）时自动调用，Python 中**不推荐使用**。
- `__dict__`：查看对象属性（只显示与 self 绑定的）或类属性。
- 用 `types.MethodType(函数, 对象)` 可给**单个对象**动态绑定/替换方法（函数名不加括号）。

### 5.2 属性与方法的分类（15）

| 类型 | 定义 | 特点 |
|---|---|---|
| 类属性 | 类体内直接定义的属性 | 所有实例共享；改类属性影响所有实例 |
| 实例属性 | `__init__` 中 `self.xxx` | 每个对象独立 |
| 实例方法 | 第一个参数 `self` | 一般由**对象**调用 |
| 静态方法 | `@staticmethod`，有自己的参数 | 与类内数据不共享；**类和对象都可调用** |
| 类方法 | `@classmethod`，第一个参数 `cls` | cls 表示类本身；用于**访问和修改类属性**，不能访问实例属性 |

- 区分：`Circle.radius = 1` 修改类属性；`self.radius = 1` 修改当前对象的实例属性。

### 5.3 封装（16，高频考点）

- 封装：把数据和方法封装在类中，通过访问权限隐藏内部实现，提高安全性与可维护性。
- 下划线规则：
  1. **单下划线前缀** `_x`：约定为"内部使用"（人为约定，程序上仍可访问）。
  2. **双下划线前缀** `__x`：真正的**私有权限**，外部无法直接访问（如 `p1.__password` 访问不到，只能通过类内方法访问）。
  3. **双下划线前后缀** `__init__` 等：Python 内置的**魔术方法**，有特殊含义，不推荐自定义。
- 应用：银行卡密码示例——私有属性 + 提供 `change_password()` 方法修改，防止外部直接篡改。

### 5.4 继承（17，高频考点）

- 被继承的类称**父类/基类**，继承者称**子类**；子类继承父类**所有**属性和方法；一个子类可有多个父类。
- 一般**不推荐修改父类属性**（会影响所有子类）。Python3 中所有类默认继承 `object`。
- **查找顺序**：子类优先；子类没有才去父类找。
- **单继承**：子类同名属性和方法**覆盖**父类。
- **多继承**：查找顺序为 **子类 > 从左到右第一个父类 > 第二个 > …**，复杂继承用 `类.mro()` 查看方法解析顺序。
- **方法重写**：子类重定义父类方法，可先调用 `父类名.__init__(self, ...)` 复用初始化。
- **super()**：按 mro 顺序搜索父类中的指定函数，并自动绑定 self；一行 `super().__init__()` 可代替多个父类的初始化（菱形继承场景）。

### 5.5 多态（18，高频考点）

- 多态：**不同对象对同一方法做出不同的响应**，让代码更灵活。
- 体现：`len()` 可用于字符串、列表、元组；不同动物类都实现 `say()`，统一用 `call(x)` 调用 `x.say()`，输出各自行为（鸭子类型：不关心对象是什么类，只关心它有没有这个方法）。

## 六、模块与包

> 来源：19.模块与包、moduleA.py

### 6.1 模块与包的导入

| 方式 | 语法 | 说明 |
|---|---|---|
| 整体导入 | `import 模块` | 调用：`模块.函数()` |
| 起别名 | `import 模块 as 别名` | 调用：`别名.函数()` |
| 部分导入 | `from 模块 import 函数` | 只导入指定内容，可直接用函数名 |
| 全部导入 | `from 模块 import *` | 受 `__all__` 限制 |

- **模块**就是一个 .py 文件；**包**是含 `__init__.py` 文件的文件夹（组织管理模块的目录结构）。

### 6.2 模块内置变量（高频考点）

- `__name__`：模块**被直接运行**时值为 `"__main__"`，被导入时为模块名。常用于：
  ```python
  if __name__ == "__main__":
      ...
  ```
  作用：让"测试代码/主逻辑"只在直接运行时执行，被导入时不执行。
- `__all__`：定义 `from 模块 import *` 时允许导出的名字列表（如 moduleA 中 `__all__ = ['add','sub']`，则 `mul` 无法被 `import *` 导入）。

### 6.3 常用内置模块（19）

- `os`：`os.path.exists()` 判断路径是否存在；`os.mkdir()` 创建文件夹。
- `time`：`time.time()` 时间戳；`time.sleep(秒)` 休眠（Python 非硬实时，时间可能不精确）。
- `random`：`randint(a, b)` 随机整数（**伪随机**）；`shuffle(列表)` 打乱顺序。

## 七、异常处理与日志

> 来源：20.异常处理机制、21.日志文件的使用

### 7.1 异常处理（20，高频考点）

```python
try:
    x = 10 / 0            # 可能发生异常的代码
except ZeroDivisionError: # 捕获指定异常
    print("除数不能为0")
except Exception as e:    # 捕获所有异常（可打印 e）
    print(e)
else:                     # 可选：没有异常时执行
    print("正常")
finally:                  # 可选：无论是否异常都执行
    print("总会执行")
```

- **异常的传递性**：函数内抛出的异常会传给调用者，若调用者也不处理，程序终止。
- **raise**：手动抛出异常 `raise 异常类型("提示")`。
- **自定义异常**：必须**继承 Exception** 类，如 `class MyException(Exception)`。
- 常见异常：`ZeroDivisionError`（除零）、`AttributeError`（访问不存在的属性）、`IndexError`（索引越界）、`KeyboardInterrupt`（手动中断）。

### 7.2 日志 logging（21）

- 级别从高到低：**CRITICAL > ERROR > WARNING > INFO > DEBUG**。
- `logging.basicConfig(level=..., filename=..., filemode=..., format=...)`：
  - `level` 设置最低显示级别（如 DEBUG 显示全部；默认只显示 WARNING 及以上，所以 debug/info 默认被"权限"过滤）。
  - `filemode='a'` 追加、`'w'` 覆盖；**basicConfig 只能调用一次，且要在其他日志操作之前**。
  - format 常用：`%(name)s`（记录器名）、`%(levelname)s`（级别）、`%(message)s`（消息）、`%(asctime)s`（时间）。
- 自定义日志处理器：`logger = logging.getLogger('名字')`。

## 八、迭代器与生成器

> 来源：22.迭代器、23.生成器（高频考点）

### 8.1 迭代器（22）

- **迭代器协议**：同时实现 `__iter__()` 和 `__next__()`：
  - `__iter__()` 返回迭代器本身（使对象可用于 for 循环）；
  - `__next__()` 每次返回下一个元素，取完抛 **`StopIteration`** 异常结束。
- **可迭代对象**：只实现 `__iter__()`（如列表、字典、字符串）。
- 关系：**所有迭代器都是可迭代对象，但不是所有可迭代对象都是迭代器**。
- 获取迭代器：`iter(obj)` 或 `obj.__iter__()`；取下一个：`next(it)` 或 `it.__next__()`。
- 特点：只能**从前往后顺序访问**；**一次性**——遍历完后再次遍历将没有输出。

### 8.2 生成器（23）

- 生成器是一种**特殊的迭代器**，按需动态生成值，**惰性求值**，节省内存。
- 用 **`yield`** 关键字定义（普通函数用 return）：调用生成器函数**不会立即执行**函数体，而是先返回生成器对象；每次调用 `__next__()`（或 for 迭代）执行到 yield 处**暂停并返回该值**，下一次从暂停处**继续执行**（状态保持）。
- 应用：斐波那契数列（无限序列按需生成）、处理大型数据集。
- 生成器同样**一次性**，遍历完失效。

## 九、正则表达式

> 来源：24.正则表达式

### 9.1 常用元字符与规则

**匹配什么字符**：

| 元字符 | 含义 |
|---|---|
| `.` | 任意字符（换行符除外） |
| `\d` / `\D` | 数字 / 非数字 |
| `\w` / `\W` | 单词字符（英文、数字、下划线）/ 非单词字符 |
| `\s` / `\S` | 空白符 / 非空白符 |

**匹配次数（量词）**：

| 量词 | 含义 |
|---|---|
| `*` | 0 次或多次（贪婪） |
| `+` | 1 次或多次（贪婪） |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,m}` | n 到 m 次 |
| `{n,}` | n 次以上 |

**匹配位置**：`^` 行首、`$` 行尾、`\b` 单词边界。

**分组与类别**：
- `(ab)` 分组，匹配内容**保存在内存**中，可用 `\n` 引用第 n 个分组的内容（如 `\1`、`\2`）。
- `(a|b)` 匹配 a 或 b。
- `[abcd]` / `[a-d]` / `[a-zA-Z0-9]` 字符类别；`[^0-9]` 取反（非数字）。

**模式**：
- 贪婪模式：尽可能多匹配；懒惰模式：尽可能少匹配（量词后加 `?`）。
- 单行模式（`re.S` 类）：`.` 匹配包括换行符；多行模式（`re.M`）：`^` `$` 匹配每一行的开头结尾。
- 高级：`(?=p)` 后面必须跟 p、`(?!p)` 后面不能跟 p、`(?<=p)` 前面必须跟 p、`(?:p)` 非捕获分组。

### 9.2 re 模块常用函数（24）

| 函数 | 作用 |
|---|---|
| `re.search(pattern, text, flags)` | 找**第一个**匹配，返回 match 对象（可用 `.group()`、`.start()`），无匹配返回 None |
| `re.findall(pattern, text, flags)` | 找**所有**匹配，返回列表；无匹配返回空列表 |
| `re.sub(pattern, repl, text, count, flags)` | 替换匹配内容（repl 可为文本或函数）；用于脱敏、格式转换 |
| `re.split(pattern, text, maxsplit)` | 按模式分割，返回列表 |
| `re.compile(pattern)` | 预编译模式（多次匹配时避免重复编译，提高效率） |

- 手机号匹配示例：`r"^[1]{1}[3589]{1}[0-9]{9}$"`。
- 日期格式转换：`re.sub(r"(\d{4})\.(\d{2})\.(\d{2})", r"\1年\2月\3日", "2002.04.20")`。
- 身份证脱敏：`r"(\d{6})(\d{4})(\d{4})(\d{3})(\d|X)"` → `r'\1******\4\5'`。

## 十、装饰器

> 来源：25.装饰器（高频考点）

### 10.1 原理

- 装饰器本质是**一种特殊的嵌套函数**：**接收一个函数作为参数（被装饰的函数），返回一个新函数**（装饰后的函数）。
- 核心作用：**在不修改被装饰函数源代码的情况下，为其添加新功能**。

```python
def decorator(f):
    def f1():
        print("b")
        f()
        print("c")
    return f1

@decorator            # 等价于 func = decorator(func)
def func():
    print("a")
```

### 10.2 带参数的装饰器（三层嵌套）

- 装饰器本身要参数时，需要**三层嵌套**：最外层收装饰器参数 → 中间层收被装饰函数 → 最内层实现功能。

```python
@func1("How are you?")        # 等价于 greet = func1("How are you?")(greet)
def greet(name):
    return f"Hello,{name}."
```

### 10.3 装饰器嵌套

- 多个装饰器同时使用时：**装饰（包装）顺序从下到上，执行顺序从上到下**。
- 即最下面的装饰器先包装原函数，其返回值作为参数传给上一层装饰器。

### 10.4 类装饰器

- 类也可作装饰器：在类中实现 **`__call__`** 方法，使类的实例可被当函数调用。

### 10.5 应用

- 日志装饰器：在函数调用前后用 logging 记录函数名、参数与返回值。

## 十一、文件操作

> 来源：26.文件操作

### 11.1 文件组成与 open()

- 文件 = **数据**（实际内容）+ **元数据**（文件名、大小、创建/修改时间、类型等）+ **文件系统**（组织管理文件、分配磁盘空间）。
- `open(file, mode='r', buffering=None, encoding=None, errors=None, newline=None)` 返回文件对象。

### 11.2 打开模式（高频考点）

| 模式 | 说明 |
|---|---|
| `r` | 只读，文件**必须存在**，否则报错 |
| `r+` | 读写，文件必须存在 |
| `w` | 只写，存在则**覆盖**，不存在则创建 |
| `w+` | 读写，存在则覆盖，不存在则创建 |
| `a` | 追加写，存在则末尾追加，不存在则创建 |
| `a+` | 读写追加（读取可能出错，指针在末尾） |
| `x` | 独占创建，文件已存在则报错（防覆盖） |
| `b` | 二进制模式（按字节处理） |
| `t` | 文本模式（按字符串处理，默认） |

### 11.3 读写方法

- `read(size)`：读 size 个字符（默认读全部，返回字符串）。
- `readline()`：读一行；`readlines()`：读所有行，返回**列表**。
- `write(str)`：写入字符串/字节（其他类型需转换），返回写入字符数。
- **文件关闭**：`close()` 释放资源、刷新缓冲区。

### 11.4 with 上下文管理器（高频考点）

```python
with open("./2.txt", 'r') as fd:
    ...
```

- with 表达式要求对象实现 **`__enter__` 和 `__exit__`** 两个方法（上下文管理器协议）。
- 进入 with-block 前调用 `__enter__`；无论正常结束还是异常，结束都调用 `__exit__`，**自动关闭文件、释放资源**。

### 11.5 文件指针

- `tell()`：返回指针当前位置距文件开头的**字节数**（读取模式有意义；UTF-8 中一个汉字占 3 字节）。
- `seek(offset, whence=0)`：移动指针；whence 0=文件开头、1=当前位置、2=文件末尾。

### 11.6 os / os.path 常用操作

- `os.mkdir()` 创建**一级**目录；`os.makedirs()` 递归创建**多级**目录；`os.rmdir()` 删除**空**目录。
- `os.getcwd()` 当前目录；`os.chdir()` 切换目录；`os.listdir()` 列出目录内容。
- `os.path.exists/isfile/isdir` 判断存在/是文件/是目录；`os.path.getsize()` 文件大小；`os.path.getmtime()` 最近修改时间（配合 `time.localtime` + `strftime` 格式化）。
- `os.path.join(path, *paths)`：拼接路径（自动处理分隔符，跨平台兼容）。
- `os.path.abspath()` 绝对路径；`os.path.split()` 拆分路径。

## 十二、多进程

> 来源：27.多进程、28.多进程通信、29~31.进程同步、32.进程池

### 12.1 进程基础（27）

- 用 `multiprocessing` 模块创建进程：`Process(target=函数, args=元组, name=, daemon=)`。
- 三步配套：**`start()`（启动）→ 并发执行 → `join()`（等待子进程结束）**，缺一不可。
- `p.pid` / `os.getpid()` 获取进程 ID；`p.name` 进程名（默认 Process-N）。
- **守护进程**（daemon=True）：主进程结束时自动终止。
- 进程状态：**僵尸进程**（已结束仍留在进程表等待父进程回收退出状态）、**孤儿进程**（父进程已结束，被 init 进程 PID=1 领养）。
- **进程间资源不共享**：全局变量在各进程中独立（子进程修改不影响主进程）。——这是与线程的关键区别。

### 12.2 进程间通信（28，高频考点）

| 方式 | 特点 |
|---|---|
| **管道 Pipe** | `Pipe()` 返回两个连接对象（两端）；**双向、点对点**（两个进程间）；`send(obj)` 发送（对象需可序列化）、`recv()` 阻塞接收、`close()` 释放；缓冲区有限，满了会阻塞 |
| **消息队列 Queue** | FIFO，基于内核；`Queue(maxsize)`；`put/get`（可配 block、timeout 参数）、`put_nowait/get_nowait`（满/空时抛 `Queue.Full`/`Queue.Empty`）、`empty/full/qsize`；不要在多个进程间共享同一个队列实例 |
| **共享内存** | 多个进程访问同一块内存，**避免数据复制、效率高**；`Value(type_code, 值)` 共享变量、`Array(type_code, 序列)` 共享数组（默认带锁保护）；`shared_memory.SharedMemory(name=, create=, size=)`，`close()` 只是关闭接口，**最后一个使用方需 `unlink()` 销毁**；数据类型有限、需同步机制防竞态 |

### 12.3 进程同步（29~31，高频考点）

**基本概念**：
- 进程同步：协调多个进程对共享资源的访问，保证任一时刻只有一个进程访问。
- **临界资源**：一段时间内仅允许一个进程访问的资源；**临界区**：访问临界资源的代码。
- 同步规则：**空闲让进、忙则等待**。

| 机制 | 说明 |
|---|---|
| **互斥锁 Lock** | 同一时间只有一个进程能访问资源；`acquire()` 获取（阻塞）、`release()` 释放（**必须释放否则死锁**）；`with lock:` 可代替 acquire/release |
| **递归锁 RLock** | 允许**同一进程多次获取同一把锁**（内部有计数器，获取 +1、释放 -1，计数为 0 才真正释放），适用于递归调用 |
| **信号量 Semaphore** | 内部维护计数器，控制**最大并发访问数量**；`acquire()` 值减一、`release()` 值加一；对应 PV 操作（P/wait 检查-1，为 0 则挂起；V/signal +1，唤醒等待进程） |
| **事件 Event** | 简单的"信号"同步：`set()` 设为真（唤醒所有等待进程）、`clear()` 设为假、`wait([timeout])` 阻塞直到被设置、`is_set()` 查状态；适合"一个进程通知其他进程某事已发生" |
| **条件变量 Condition** | 可看作"锁 + 条件队列"：`acquire/release`、`wait()`（释放内部锁并阻塞，被 notify 唤醒后重新抢锁）、`notify(n)` 唤醒 n 个、`notify_all()` 唤醒全部；默认为 RLock |

**死锁**（必考）：
- 定义：多个进程互相等待对方持有的资源，全部无法继续执行。
- 四个必要条件：**互斥条件、占有和等待条件、不可抢占条件、循环等待条件**。
- 避免：及时释放锁、避免嵌套加锁、使用 RLock/with 等。

### 12.4 进程池（32）

- 思想：**先创建好一批空闲进程，有任务再分配**（先有进程后有任务），避免频繁创建/销毁的开销。
- `multiprocessing.Pool(processes=)`：`apply()` 阻塞、`apply_async()` 异步、`map()` 并行映射（全部执行完才返回）、`imap()` 立即返回可迭代对象。
- **ProcessPoolExecutor**（`concurrent.futures`）：
  - `submit(fn, *args)` 提交任务并**返回 Future 对象**，用 `future.result()` 取结果。
  - `map(fn, iterable, timeout, chunksize)` 并行执行；chunksize 控制每次提交给进程的任务量。
  - `shutdown(wait=True)` 关闭池；**with 语句结束时自动调用 shutdown**。
  - `max_workers` 默认等于 CPU 核心数。

## 十三、多线程

> 来源：33.多线程、34.定时器、35.线程通信、36.线程同步、37.线程池

### 13.1 线程与进程（33，必考）

- **进程**是资源分配的最小单位；**线程**是 CPU 调度的最小单位，是进程内的实际执行单元。
- 线程创建只申请自身必须的资源，**共享进程的内存空间等资源**；线程不具备进程级隔离性，进程崩溃则其内所有线程终止。

### 13.2 GIL 全局解释器锁（必考）

- CPython 中，**GIL 保证同一时刻只有一个线程执行 Python 字节码**。
- 后果：即使是多核 CPU，**多线程无法实现真正的并行计算**（Python 的并发是"伪并发"），对 CPU 密集型任务效率受限。
- **多进程不受 GIL 限制**：每个进程有独立的解释器和内存空间，可充分利用多核 CPU 并行计算。

### 13.3 threading 模块（33）

- `threading.Thread(target=, name=, args=, kwargs=, daemon=)` 创建线程。
- 方法：`start()` 启动（调用 run() 并在**新线程**中执行——**不要直接调用 run()**，直接调用会在当前线程同步执行）；`join(timeout)` 等待结束；`is_alive()` 是否存活；`getName/setName`、`isDaemon/setDaemon`（start 之前设置）；属性 `name`、`ident`（线程标识符）、`daemon`。

### 13.4 定时器 Timer（34）

- `threading.Timer(interval, function, args=, kwargs=)`：Timer 是 Thread 的**子类**，间隔 interval 秒后执行 function。
- `start()` 启动；`cancel()` 取消（已运行则无效）。
- 应用：定时打印时间；若在函数内部再次创建 Timer 可实现周期执行（递归定时）。

### 13.5 线程通信（35）

- `queue` 模块提供**线程环境**的队列（进程间不能用）：`queue.Queue`（FIFO）、`queue.LifoQueue`（LIFO）、`queue.PriorityQueue`（优先级队列，**数值越小优先级越高**，同优先级按入队顺序）。
- `Queue(maxsize)`：maxsize <= 0 表示无限（**注意一定要设置大小**）。
- `put/get`（含 block、timeout 参数）、`put_nowait/get_nowait`、`qsize/empty/full`。
- **生产者-消费者模式**：`task_done()` 表示一个任务处理完成（每次 get 后调用）；`join()` 阻塞直到队列中所有任务都有对应的 task_done；可用 `put(None)` 发送结束信号。

### 13.6 线程同步：屏障 Barrier（36）

- `threading.Barrier(parties, action=None, timeout=None)`：让一组线程在某个点集合，**全部到达屏障点才一起继续**；任一线程未到达则全部阻塞。
- `wait()` 阻塞直到屏障释放（返回 0 ~ parties-1 的整数）；`reset()` 重置（还有线程等待时调用会抛异常）；`abort()` 使屏障破损（之后所有 wait 抛异常）。
- 属性：`parties`（需要的线程数）、`n_waiting`（当前阻塞数）、`broken`（是否破损）。

### 13.7 线程池 ThreadPoolExecutor（37）

- `ThreadPoolExecutor(max_workers=5)` + `with`：`submit(fn, *args)` 返回 Future；`map(fn, iterable, timeout, chunksize)` 并行执行（chunksize **对线程池无效**）；with 结束时自动 shutdown。

## 十四、数据结构

> 来源：38.单链表、39.双链表、栈.py、40~42.队列、43.哈希表、44.递归

### 14.1 链表（38、39）

**单链表**：节点 `Node(data, next)`；链表对象维护**私有头指针 `__head`**（双下划线私有属性）。

| 操作 | 思路 |
|---|---|
| `is_empty()` | 判断 `__head` 是否为 None |
| `length()` / `travel()` | 游标 `current` 从 head 出发，沿 `next` 遍历 |
| `add(data)` 头插法 | 新节点 `next` 指向原 head，head 指向新节点 |
| `append(data)` 尾插法 | 空链表直接设为 head；否则遍历到最后一个节点接上 |
| `insert(pos, data)` | pos<=0 用头插；pos>length 用尾插；否则找到 pos-1 处节点插入 |
| `remove(data)` | 找到目标节点，让前驱 `pre.next = current.next`；**删除头节点**要特殊处理；找到后 break |
| `search(data)` | 遍历比较，找到返回 True |

**双链表**：节点 `Node(data, next, prev)`；插入/删除时要**同时维护 next 和 prev 两个指针**，且要处理头节点、尾节点、唯一节点的边界情况。

### 14.2 栈 Stack（栈.py）

- **后进先出（LIFO）** 的受限线性表，只能在一端（**栈顶**）操作。
- 方法：`push(data)` 入栈（列表 append）、`pop()` 弹出栈顶（列表 pop，空栈返回 None）、`peek()` 查看栈顶（`list[-1]`，不弹出）、`is_empty()`、`size()`。

### 14.3 队列（40~42）

- **队列**：**先进先出（FIFO）**；队尾插入、队头删除，不允许中间操作。
- 列表实现：`enqueue` = append，`dequeue` = pop(0)；`is_empty()`、`size()`。
- `queue.Queue` 内置实现：`put/get/qsize/empty/full`。
- **双端队列 deque**：头部和尾部都可插入删除（兼具队列和栈的性质）：`add_front`（insert(0, x)）、`add_rear`（append）、`remove_front`（pop(0)）、`remove_rear`（pop）。

### 14.4 哈希表（43，高频考点）

- 哈希表通过**哈希函数**把键（key）映射到存储位置，插入/查找/删除平均时间复杂度接近 **O(1)**。
- **哈希函数**：把任意大小的数据转换为**固定长度的整数**（哈希值），用于快速查找、比较、索引。
- 注意：**可变对象通常不可哈希**（值改变会导致哈希值不一致），所以字典的键必须是不可变类型。
- **哈希冲突**：不同 key 经哈希函数得到相同地址。解决方案：
  1. **开放寻址法**：冲突时向后探查新位置存储；
  2. **链地址法（拉链法）**：每个位置挂一个链表，冲突元素追加到链表末尾。
- **Python 的 dict 底层就是哈希表**：对键做哈希快速定位存储位置，查找速度与字典大小无关。

### 14.5 递归（44，高频考点）

- 递归：把问题分解为**规模更小的相同问题**，直到可直接解决；算法特征是**调用自身**。
- **递归三定律**：
  1. 必须有**基本结束条件**（最小规模问题的直接解决）；
  2. 必须**改变状态向结束条件演进**（减小问题规模）；
  3. 必须**调用自身**（解决规模减小后的相同问题）。
- 示例：斐波那契——迭代版（循环维护 a, b）与递归版（`f(n-1)` 的结果 + 最后两项）对比。

## 十五、查找与排序

> 来源：45~51

### 15.1 查找（45）

- **线性查找**：从头到尾逐个比较，O(n)，无需排序。
- **二分查找**：每次取中间值比较，缩小一半范围；**前提是序列有序**；时间复杂度 **O(log n)**。注意：`num_list.sort()` 原地排序（改变原列表），`sorted()` 返回新列表不改变原列表。

### 15.2 排序算法对比表（46~51，必考）

| 算法 | 思想 | 时间复杂度（平均） | 稳定性 |
|---|---|---|---|
| 冒泡排序 | 相邻两两比较，大的"冒泡"到末尾；每轮排好最大元素 | O(n²) | **稳定** |
| 选择排序 | 每轮从剩余元素中选出**最小**的，与第 i 位交换 | O(n²) | 不稳定 |
| 插入排序 | 认定第一个元素有序，把后面的元素**插入**到有序序列的正确位置（`arr[j+1] = arr[j]` 向后挪） | O(n²) | **稳定** |
| 希尔排序 | 插入排序的改进（**缩小增量排序**）：按 gap 分组做插入排序，gap 不断减半直到 1 | 介于 O(n)~O(n²) | 不稳定 |
| 快速排序 | **分治**：选**基准元素** pivot，小于基准放左边、大于放右边，递归排序左右 | O(n log n) | 不稳定 |
| 归并排序 | **分治**：不断二分到单个元素，再**两两有序合并**（merge 函数用双指针归并） | O(n log n) | **稳定** |

**各算法核心要点（答辩表述）**：
- **冒泡**：`for i in range(1, len)`（轮数）内嵌 `for j in range(0, len-i)`（每轮少比一个，`arr[j] > arr[j+1]` 则交换）。
- **选择**：外层 i 定位置，内层找 `[i+1, n)` 中最小值的索引 `min_idx`，一轮结束交换 `arr[i]` 与 `arr[min_idx]`。
- **插入**：`key = arr[i]` 保存待插入值，`while j >= 0 and key < arr[j]` 时把 `arr[j]` 后移，最后 `arr[j+1] = key`。
- **希尔**：`gap = n // 2`，组内插入排序，`gap //= 2` 直到 0。
- **快排**：递归终止条件 `len(arr) <= 1`；选 `pivot = arr[0]`，用列表推导式分 left/middle/right 三部分再递归合并（含等于基准的元素，防止死循环/重复丢失）。
- **归并**：`mid = len(arr) // 2` 切分，递归排序左右，`merge()` 中双指针比较、较小的先入结果，剩余部分 `extend` 追加。

## 十六、答辩高频问答

### Q1：列表和元组的区别？
元组**不可修改**（不可变），列表可变；列表方法更多（增删改）。元组可用作字典的键（不可变），列表不能。元组因不可变更安全，遍历通常略快。

### Q2：浅拷贝和深拷贝的区别？
浅拷贝只复制**第一层**：新对象与原对象内容一致，但内部**可变元素仍是原引用**（改新对象的嵌套列表会影响原对象）；深拷贝（`copy.deepcopy`）创建**完全独立**的副本，任意修改互不影响。不可变元素（数字、字符串）不受影响。

### Q3：迭代器和生成器有什么区别？
- 迭代器需实现 `__iter__` 和 `__next__`；生成器是**特殊的迭代器**，用 `yield` 实现，写法更简单。
- 生成器**惰性求值**：不一次性生成所有值，内存占用小；且每次 yield 后**暂停并保持状态**，下次从暂停处继续。
- 两者都是**一次性**的，只能前向遍历。

### Q4：多进程和多线程的区别？什么时候用哪个？
- 进程：资源分配单位，**资源相互独立**，不受 GIL 限制，可真正并行——适合 **CPU 密集型**任务；但创建开销大、通信复杂（Pipe/Queue/共享内存）。
- 线程：调度单位，**共享进程内存**，切换开销小——适合 **I/O 密集型**任务；但受 **GIL** 限制无法真正并行执行 Python 字节码。

### Q5：GIL 是什么？
CPython 的**全局解释器锁**，保证同一时刻只有一个线程执行 Python 字节码，因此多线程无法利用多核做真正的并行计算；多进程因各自拥有独立解释器而**不受 GIL 限制**。

### Q6：进程间通信的方式有哪些？
管道 Pipe（双向、点对点）、消息队列 Queue（FIFO，多进程适用）、共享内存（Value/Array/SharedMemory，效率最高但要自己同步）。

### Q7：进程/线程同步机制有哪些？各适用什么场景？
- **Lock 互斥锁**：同一时间只允许一个进程/线程访问资源，防竞态。
- **RLock 递归锁**：同一线程可重复加锁（有计数器），用于递归场景。
- **Semaphore 信号量**：限制最大并发访问数量（如限流）。
- **Event 事件**：一个进程发信号唤醒其他等待进程（简单通知场景）。
- **Condition 条件变量**：锁 + 条件队列，配合 notify/wait 实现复杂同步（生产者-消费者）。
- **Barrier 屏障**：让一组线程全部到达某个点后才一起继续。

### Q8：死锁是什么？产生的条件？
多个进程/线程互相等待对方持有的资源，全部无法推进。四个必要条件：**互斥、占有且等待、不可抢占、循环等待**。避免方法：及时释放锁、统一加锁顺序、用 RLock、用 with 管理锁。

### Q9：面向对象三大特性？
- **封装**：把数据和操作打包进类，用下划线权限（双下划线私有）隐藏内部实现，提高安全性可维护性。
- **继承**：子类复用父类属性和方法；单继承覆盖、多继承从左到右查找（mro）；可方法重写；`super()` 按 mro 调用父类方法。
- **多态**：不同对象对同一方法做出不同响应（如统一调用 `say()` 输出不同叫声），代码更灵活。

### Q10：`__init__` 和 `__new__`、`__del__` 的作用？
`__init__` 构造函数：创建对象时自动调用，初始化属性。`__del__` 析构函数：对象销毁时自动调用，Python 不推荐使用（调用时机不确定）。`__new__` 真正创建对象（先于 `__init__`）。

### Q11：`__name__ == "__main__"` 的作用？
区分模块是**被直接运行**还是**被导入**：直接运行时 `__name__` 为 `"__main__"`。用它包裹测试/主逻辑，可让模块被导入时不执行这些代码。

### Q12：装饰器的作用和原理？
在不修改原函数代码的前提下**扩展功能**。本质是嵌套函数：接收函数作参数、返回新函数；`@decorator` 是 `func = decorator(func)` 的语法糖。带参数装饰器需三层嵌套；类装饰器靠 `__call__`。

### Q13：`with` 语句的原理？
上下文管理器：对象需实现 `__enter__`（进入时调用，返回值赋给 as 变量）和 `__exit__`（无论正常还是异常退出时都调用，负责清理资源，如关闭文件）。

### Q14：闭包是什么？
内层函数引用了外层函数的变量，外层函数返回内层函数；该变量**不会随外层函数结束而销毁**，被内层函数保留（如求 n 次方函数的生成器）。

### Q15：哈希冲突怎么解决？
开放寻址法（冲突后向后探测空位）、链地址法（每个槽位挂链表，冲突元素追加）。Python dict 底层就是哈希表，平均操作复杂度 O(1)。

### Q16：递归的三定律？
必须有基本结束条件；必须向结束条件演进（缩小规模）；必须调用自身。

### Q17：二分查找的前提和时间复杂度？
前提：**序列有序**（需先排序）。每次折半，时间复杂度 **O(log n)**。

### Q18：`sort()` 和 `sorted()` 的区别？
`list.sort()` 是列表的**原地**方法（修改原列表，返回 None）；`sorted()` 是内置函数，返回**新的列表**，原序列不变，可用于任何可迭代对象。

### Q19：`is` 和 `==` 的区别？
`is` 判断是否为**同一个对象**（比较地址 id）；`==` 判断**值是否相等**。

### Q20：进程池 / 线程池的优点？
预先创建一批空闲进程/线程（先有进程后有任务），任务到来直接分配，**避免频繁创建销毁的开销**；`submit` 返回 Future，`map` 批量并行；with 语句自动 shutdown。

## 十七、易错点自查

> 以下是从代码中提炼的常见"坑"，答辩时如被问到相关代码细节需留意：

1. **`input()` 返回字符串**：做数值运算前必须 `int()` / `float()` 转换。
2. **整除用 `//`**：`num // 10 % 10` 取十位；用 `/` 会得到浮点数。
3. **默认参数必须在最右边**；位置参数不能出现在关键字参数之后。
4. **`*args` 后面还有形参时**，那些形参必须用关键字传参。
5. **字典解包 `func(**d)`** 要求字典 key 与形参名完全对应（顺序无所谓）。
6. **`sort()` 与 `sorted()`**：前者原地排序返回 None，后者返回新列表。
7. **集合的 `pop()` 是随机删除**（与列表的 pop 不同），且无法指定元素。
8. **`set()` 的参数必须是可迭代对象**；`set(1)` 会报错。
9. **字典没有 `remove` 方法**，删除用 `pop(key)` 或 `del`。
10. **迭代器和生成器都是一次性的**，遍历完再遍历没有输出。
11. **生成器函数调用时不执行函数体**，返回生成器对象；`__next__()` 才真正执行到 yield。
12. **列表的 `remove()` 返回 None**；`pop()` 才返回被删除元素。
13. **双下划线私有属性**外部无法直接访问（如 `__password`），只能通过类内方法。
14. **用 `del` 删除对象属性**只能删实例自己的属性，不能删类属性。
15. **`from 模块 import *`** 受 `__all__` 限制，未列出的名字不会被导入。
16. **`logging.basicConfig` 只能调用一次**，且要在其他日志操作前。
17. **多进程必须三步配套**：`start()` → 执行 → `join()`；`join` 不写则主进程不会等待子进程。
18. **进程间全局变量不共享**，线程间共享——这是两者核心差异。
19. **进程的 Queue 和线程的 queue.Queue 不能混用**。
20. **使用互斥锁后必须 `release()`**，否则死锁；推荐 `with lock:`。
21. **共享内存最后要 `unlink()` 销毁**；`close()` 只关闭接口不清空内存。
22. **Timer/Thread 直接调用 `run()`** 不会开新线程，会同步执行，必须用 `start()`。
23. **队列 `put/get` 默认阻塞**；`put_nowait/get_nowait` 在满/空时立即抛异常。
24. **PriorityQueue 数值越小优先级越高**。
25. **`seek(offset, whence)`** 中 whence：0 开头、1 当前位置、2 末尾；`tell()` 返回的是**字节数**（UTF-8 汉字占 3 字节）。
26. **`w` 模式会覆盖原文件**；想保留内容用 `a` 追加。
27. **快速排序递归终止条件** `len(arr) <= 1` 不能省，否则无限递归。
28. **二分查找前必须先排序**；`sort()` 会改变原列表。
29. **`frozenset` 不可变集合**：元素和元素个数都不能改。
30. **格式化精度 `{:.2f}`**：m.n 中 n 是小数位数。
